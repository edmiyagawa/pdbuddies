Instructions

How to use Pixie Dust Buddies

Use the tabs together to plan routes, prepare themed gifts, track celebration moments, and save photo memories during the sailing.

Route

  1. Use Search, Deck, Character Group, and Ship Section to narrow the room list.
  2. Select a From and To room or Other Location to generate walking steps.
  3. Use the 3D route view to check deck changes and lift travel.
  4. Tap Pixie Dusted after a room has received its pixie dust.

Gifts

  1. Click a character category card to filter the packing slips below.
  2. Use All categories to reset the category filter.
  3. Gift categories are based on the Preferred characters column in the Google Sheet.
  4. The number on each category is the exact number of matching gifts to prepare.

Celebration

  1. Click a celebration card to filter by the same celebration tags shown in Route.
  2. Use All celebrations to reset the celebration filter.
  3. Celebration categories are based on the Special event column in the Google Sheet.
  4. Use celebration boosters for rooms with tagged milestones.

Photos

  1. Add a stateroom number, caption, and photo from the Photos tab.
  2. Only staterooms in the current records can add photos.
  3. Each stateroom can save up to 5 photos on the current device.
  4. Use Remove to delete a saved photo from this browser.

Data & Sharing

  1. The app reads the live Google Sheet when loaded online or through the local server.
  2. Pixie Dusted status and photos are saved only in the current browser on the current device.
  3. Refreshing keeps local status and photos, but another device will have its own saved items.
  4. Update the Google Sheet to change room, gift, or event data.
